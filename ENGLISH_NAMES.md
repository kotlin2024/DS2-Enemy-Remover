# English naming provenance

The 96 English display names are based on the **English variant labels already preserved in `catalog.json`**, with the English-language enemy index below used for community naming and search aliases. They are not machine translations of the Korean family labels.

Reference: https://darksouls2.wikidot.com/enemies (consulted 2026-10-10).

The original English variant labels remain available in `english_names.json` as search aliases, including weapon/phantom descriptions. English community aliases such as Amana Shrine Maiden, Ice Hedgehog and Frozen Reindeer are also searchable. Some original labels and community names differ; grouping the same allow-listed parameter IDs does not change gameplay scope.

Examples: family 511 uses **Imperious Knight** from the English variant source, rather than translating its existing Korean label; family 654 uses **Scorcher**, and family 665 uses **Sanctum Guardian** with Sanctum Knight as a search alias. Family 105 contains Amana healers/casters and is displayed as **Amana Priestess**. These are source-based family names, not assertions that every name is officially localized by the game publisher.

`english_names.json` covers exactly the existing 96 families. No new enemy ID, boss or NPC is added by changing language. The UI accepts Korean names, English display names, original English variant labels and IDs in either language.
