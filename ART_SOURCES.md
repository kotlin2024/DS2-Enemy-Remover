# Artwork

The bundled `assets/mascot-*.png` icons were extracted from the developer's existing DS3 trainer mascot atlas (8 x 8 cells). No Dark Souls game textures or models are bundled. They are illustrative species symbols, not exact DS2 portraits.

The original mascot illustrations were created with generative AI for the earlier trainer. This DS2 version reuses those images; it did not generate new illustrations. The knight and dog are used in the header, with no basilisk illustration in that header.

The image assets and application icon are included so reviewers can build and inspect the complete UI. This document does not grant a separate redistribution license for them.
